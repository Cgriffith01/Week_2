# Week 2 Exercises

Two small standalone Python exercises: one working with a list, one working with basic math and formatted output.

## Files

- **Exercise_week_2_a_.py** - builds and manipulates a list of birds (add, sort, loop, remove).
- **Exercise_week_2_b_.py** - a tip calculator that takes a meal cost and shows the tip and total at 15%, 18%, and 20%.

## Exercise (a): Bird List

1. Starts with a list of four birds and prints it.
2. Asks you to enter another bird, then adds it to the list.
3. Sorts the list alphabetically and prints each bird on its own line.
4. Removes the bird at index 1 with `.pop()` and announces which one was removed.
5. Removes the last bird in the list with `del`.

### Usage

```
python3 Exercise_week_2_a_.py
```

## Exercise (b): Tip Calculator

1. Asks for the total cost of the meal.
2. Calculates the tip amount and total bill for 15%, 18%, and 20% tips.
3. Prints all three, formatted to two decimal places.

Entering something that isn't a number is caught and reported instead of crashing the program.

### Usage

```
python3 Exercise_week_2_b_.py
```

## Requirements

- Python 3
